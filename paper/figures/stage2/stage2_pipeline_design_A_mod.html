Stage 2 — Training Architecture

Compact training view for side-by-side layout with stage 3. Target H&E provides both the clean latent path and the UNI style embedding; cell mask shapes the Q tokens inside TME cross-attention, and only the fused residual sum reaches the trainable ControlNet while the base transformer and encoders stay frozen.

Training path only. The loss is applied in latent noise space: frozen SD3.5 VAE encodes the target H&E to x0, forward diffusion produces x_t and eps, and the Multi-Group TME module uses the mask latent as Q tokens with zero_mask_latent=True so fused = tme(vae_mask) - vae_mask = Σ(Δgroup). Residuals only are sent to ControlNet.
